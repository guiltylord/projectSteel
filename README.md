# projectSteel

Универсальный парсер с автоматическим прохождением капч (OCR) на базе Playwright и ddddocr.

## 📋 Описание

Проект предназначен для автоматизации взаимодействия с веб-сайтами: заполнение форм, клики, обход капч и сохранение результатов.

## 🏗️ Структура проекта

```
projectSteel/
├── src/
│   ├── main.py              # Точка входа (контроллер)
│   ├── engine_modern.py     # Современный движок (с улучшенным вводом)
│   ├── engine_classic.py    # Классический движок
│   ├── converter.py         # Конвертер кода из Playwright Codegen
│   └── inspector.py         # Интерактивный инструмент для сбора селекторов
├── scenarios.json           # Конфигурация сценариев парсинга
├── requirements.txt         # Зависимости проекта
└── records/                 # Папка для сохранённых записей
```

## 📦 Установка

1. Установите зависимости:

```bash
pip install -r requirements.txt
```

1. Установите браузеры Playwright:

```bash
playwright install chromium
```

1. Требуется Python 3.10+

## 🚀 Использование

### Запуск парсера

Запуск из корня проекта:

```bash
python src/main.py -s <имя_сценария> -d <аргумент1> <аргумент2> ...
```

**Параметры:**

- `-s` — имя сценария из `scenarios.json`
- `-d` — данные для передачи в сценарий (через пробел)

**Пример:**

```bash
python src/main.py -s scenario_name -d "Иванов" "Иван" "Москва"
```

Движок автоматически выбирается из сценария (поле `engine`: `modern` или `classic`).

### Создание сценариев

#### Способ 1: Через `converter.py` (рекомендуется)

1. Запишите действия в Playwright Codegen
2. Скопируйте сгенерированный код
3. Запустите конвертер:

```bash
python src/converter.py
```

4. Вставьте код и следуйте инструкциям

#### Способ 2: Через `inspector.py` (интерактивный)

1. Запустите инспектор:

```bash
python src/inspector.py
```

1. Введите URL сайта
2. Наводите курсор на элементы и вводите команды:
  - `f` — поле ввода (Fill)
  - `s` — выбор из списка/дата (JS Set)
  - `c` — клик (Click)
  - `ci` — картинка капчи
  - `cn` — поле ввода капчи
  - `cs` — кнопка отправки капчи
  - `r` — обновить подсветку
  - `q` — выход и сохранение

### Формат `scenarios.json`

```json
{
  "scenario_name": {
    "url": "https://example.com",
    "actions": [
      {
        "type": "fill",
        "selector": "placeholder:Поиск",
        "arg_index": 0
      },
      {
        "type": "click",
        "selector": "role:button[name='Найти']"
      }
    ],
    "captcha": {
      "image": "#captcha-img",
      "input": "#captcha-input",
      "submit": "role:button[name='Отправить']",
      "refresh": "#captcha-refresh",
      "max_tries": 5
    }
  }
}
```

**Типы действий:**

- `fill` — заполнение поля (с эмуляцией событий для React/Vue)
- `click` — клик по элементу
- `dropdown` — выбор значения из выпадающего списка
- `js_inject` — JS-инъекция значения (для сложных полей)

**Форматы селекторов:**

- `role:button[name='Текст']` — по роли ARIA
- `placeholder:Текст` — по placeholder
- `text:Текст` — по тексту
- `#id`, `.class` — обычные CSS-селекторы

## 🔧 Особенности

- **Автоматическое прохождение капч** с помощью OCR (ddddocr)
- **Поддержка React/Vue** — эмуляция событий ввода для фреймворков
- **Гибкая система селекторов** — кастомные и стандартные CSS
- **Многократные попытки** — автоматическое обновление капчи при неудаче

## 📁 Вывод

При успешном выполнении результат сохраняется в:

- `out_modern.html` — для Modern Engine
- `out_classic.html` — для Classic Engine

## 📝 Зависимости

- `playwright` — автоматизация браузера
- `ddddocr` — распознавание капч
- См. `requirements.txt` для полного списка
